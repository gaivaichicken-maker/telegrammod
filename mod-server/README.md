# Ретранслятор фейк-подарков

Небольшой сервер, через который мод-юзеры обмениваются **косметическими**
фейк-подарками. Сервер хранит только их в памяти и ничего не знает про Telegram.

## Запуск

```bash
# Node.js 18+
PORT=8787 SECRET=мой-секрет node relay-server.js
```

На Windows (PowerShell):

```powershell
$env:PORT='8787'; $env:SECRET='мой-секрет'; node relay-server.js
```

Сервер должен быть доступен из интернета (VPS, хостинг, туннель типа ngrok).
Для теста можно поднять локально.

## Как связать с модом

1. Установи мод, открой **Настройки → Мод**.
2. Войди как владелец (юзернейм должен совпадать с указанным в моде).
3. Нажми **«Настроить ретранслятор»** и укажи:
   - **URL** — например `http://мой-сервер:8787`
   - **Секрет** — тот же, что в `SECRET` при запуске сервера.
4. Теперь «Отправить фейк-подарок» шлёт подарок получателю,
   а «Проверить входящие (фейк)» забирает входящие.

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | проверка живости |
| POST | `/send` | отправить подарок `{secret, from, to, gift, name}` |
| GET | `/pending?secret=&user=` | забрать входящие и очистить очередь |

## Безопасность
- Секрет общий — не публикуй его.
- В памяти хранятся только пары «кому/что», без истории.
- Это косметика: подарок помечается как «фейк» и не имеет реальной ценности.
